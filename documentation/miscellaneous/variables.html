src/app/core/http/api-url-interceptor.ts

API_BASE_URL
Type : unknown
Default value : new InjectionToken<string>('API_BASE_URL', { providedIn: 'root', factory: () => '/api', })

Préfixe des requêtes backend. En développement, ng serve relaie /api vers json-server (proxy.conf.json) ; un déploiement fournit sa propre valeur sans toucher aux services d'API.
apiUrlInterceptor
Type : HttpInterceptorFn
Default value : (req, next) => { if (!req.context.get(API_REQUEST)) { return next(req); } const base = inject(API_BASE_URL).replace(/\/+$/, ''); const path = req.url.replace(/^\/+/, ''); return next(req.clone({ url: `${base}/${path}` })); }

Proxification : products/12 → /api/products/12, uniquement pour les requêtes d'ApiService.

src/app/infra/api/api-service.ts

API_REQUEST
Type : unknown
Default value : new HttpContextToken<boolean>(() => false)

Marque une requête comme destinée au backend : seules ces requêtes sont préfixées par API_BASE_URL (proxification) et reçoivent le jeton d'authentification.

src/app/core/auth/auth-interceptors.ts

authInterceptor
Type : HttpInterceptorFn
Default value : (req, next) => { const token = inject(AuthService).token(); if (!token || !req.context.get(API_REQUEST)) { return next(req); } return next(req.clone({ setHeaders: { Authorization: `Bearer ${token}` } })); }

Injecte le jeton de session, uniquement sur les requêtes destinées au backend.
unauthorizedInterceptor
Type : HttpInterceptorFn
Default value : (req, next) => { const auth = inject(AuthService); const router = inject(Router); return next(req).pipe( catchError((error: unknown) => { if ( error instanceof HttpErrorResponse && error.status === 401 && req.context.get(API_REQUEST) && auth.isAuthenticated() ) { auth.clear(); void router.navigate(['/login'], { queryParams: { returnUrl: router.url } }); } return throwError(() => error); }), ); }

Session expirée : sur un 401 du backend alors qu'une session existe, retour à la connexion.
