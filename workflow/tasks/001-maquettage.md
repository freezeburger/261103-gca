# Tache 001 — Maquettage fonctionnel

1. Examiner les schemas applicatifs, l'organisation Angular et les conventions visuelles existantes.
2. Definir les parcours, donnees et elements d'interface des cinq ecrans demandes : connexion, recherche produits, detail produit, modification produit et recapitulatif des notifications.
3. Produire une maquette image pour chaque ecran dans `workflow/maquette`.
4. Verifier la presence, le format et la coherence des cinq maquettes avec les schemas.
5. Rediger le rapport de tache numerote dans `workflow/reports`, puis creer un commit multiligne normalise incluant le rapport et les livrables.
